# Test Repository

## Project Overview

This repository contains short sample programs organized by language. The intent is to provide small, clear examples you can compile/run quickly. Each language set is placed under a directory named after the feature branch that would typically contain those files in a multi-branch workflow.

- `feature/c-programs` : C language examples
- `feature/cpp-programs` : C++ language examples
- `feature/python-programs` : Python language examples
- `feature/java-programs` : Java language examples
- `feature/javascript-programs` : JavaScript language examples

Each language folder contains 3–6 small example programs demonstrating basic syntax and common tasks.

## How to use

- For C/C++: compile with `gcc`/`g++` and run the produced executable.
- For Java: compile with `javac` and run with `java`.
- For Python/JavaScript: run with the appropriate interpreter: `python` or `node`.

Enjoy exploring the examples!
